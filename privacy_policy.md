# Privacy Policy for SkillNest

**Last Updated:** September 23, 2026

**SkillNest** ("we", "our", or "the App") is committed to protecting your privacy. This Privacy Policy explains how information is handled when you use the SkillNest mobile application (Package Name: `com.learningvault.learning_vault`).

---

## 1. Offline-First Architecture & Local Data Storage

SkillNest is designed from the ground up as an **offline-first** learning library and knowledge organizer.

- **Your Content Stays on Your Device:** All resources, saved links, custom notes, sticky notes, tags, collection hierarchies, reading progress, and local file attachments (e.g. PDFs, images) are stored **100% locally on your device** using an encrypted/isolated SQLite database and your device's private app storage sandbox.
- **No Account Required:** You can use SkillNest without creating an account, registering an email, or logging in.

---

## 2. Information Handled by Third-Party Services

To provide reliable push notifications and understand general application stability, SkillNest integrates select Google Firebase services:

### A. Firebase Cloud Messaging (FCM)

- **Purpose:** Delivers optional learning reminders, study nudges, and application updates.
- **Data Collected:** An anonymous, randomized FCM device registration token generated by Google Play services.
- **Privacy Safeguard:** FCM tokens are used exclusively to deliver notifications and are never linked to personal identities, sold, or shared with third parties.

### B. Firebase Analytics

- **Purpose:** Helps us understand general app usage patterns (e.g., app launches, feature adoption) to improve stability and user experience.
- **Data Collected:** Aggregated, non-personally identifiable telemetry events (such as `app_open`, `resource_created`, `collection_created`) and standard device metadata (device model, OS version).
- **Strict Privacy Safeguard:** SkillNest **never** sends personal data, URLs, article titles, note text, file names, or library contents to Firebase Analytics.

### C. Firebase Remote Config & In-App Messaging

- **Purpose:** Provides non-intrusive feature flags and in-app guidance.
- **Data Collected:** Anonymous device configuration parameters without collecting personal user data.

---

## 3. Device Permissions & Why They Are Needed

SkillNest requests only the minimum permissions necessary for its features:

| Permission               | Purpose                                                                                                                                                           |
| :----------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `INTERNET`               | Required to fetch website OpenGraph metadata (thumbnails, titles) when you save a web link, and to receive Firebase Cloud Messaging notifications.                |
| `POST_NOTIFICATIONS`     | (Android 13+) Required to show learning reminders, streak alerts, and system notification messages. You can grant or revoke this at any time in Android Settings. |
| `RECEIVE_BOOT_COMPLETED` | Allows the app to reschedule your active learning reminders after your device restarts.                                                                           |

> SkillNest does **not** request broad storage permissions (such as `READ_EXTERNAL_STORAGE` or `MANAGE_EXTERNAL_STORAGE`). File selection and attachment handling use Android's secure Storage Access Framework (SAF).

---

## 4. User-Initiated Backups & Data Portability

- SkillNest allows you to create **full offline ZIP backups** containing your database and attachments with SHA-256 integrity checksums.
- Backups are generated locally and saved strictly to the folder or cloud storage destination you choose. We have no access to your backup files.

---

## 5. Data Retention & Deletion

- You have full ownership and control over your data.
- Deleting an item or clearing data inside the app permanently deletes it from your device's SQLite database and local disk storage.
- Uninstalling the application completely removes all locally stored library files and app data from your device.

---

## 6. Children's Privacy

SkillNest is intended for general audiences and does not knowingly collect any personally identifiable information from children under the age of 13.

---

## 7. Security

We apply industry-standard security practices, including scoped storage isolation, path traversal protection, SHA-256 integrity verification for backups, and ProGuard/R8 code minification in release builds.
